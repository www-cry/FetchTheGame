# Fetch-The-Game

Fetch the game is an arcade 2D game where you must throw the ball to your dog!

# The controls are:
In the settings: 
*   - "+" "-" for the volume adjustment
    - A D to change the player skin
    - Arrow Left Arrow right to adjust the amount of required fetches for win condition (the maximum number is 10)
During the game:
* - W A S D for movement
  - hold LShift for faster movement
  - LMB(press or hold for stronger throw) to throw the ball
  - R to restart the game

# Tech stack used:

Language: C++

Framework: SFML 3.0

BuildSys: CMake

# How to run the build:

1) Clone the repo

   git clone https://github.com/www-cry/FetchTheGame.git
   cd FetchTheGame

2) Create & open build directory

   mkdir build
   cd build

3) Configure project with CMake

   cmake ..

4) Build the .exe

   cmake --build . --config Release
